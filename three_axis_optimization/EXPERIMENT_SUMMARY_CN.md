# VLA-Perf 三轴优化实验汇总

## 1. 实验设置

统一实验使用 π0 的 3-camera、256 vision tokens、800 VLM prefix tokens、
50 action tokens 和 10 个 denoising steps。跨帧实验统计连续 8 帧的平均延迟：
首帧建立缓存，后续 7 帧的相似度为 0.92，reuse gate 为 0.85；每个后续帧
支付 0.02 ms 相似度验证开销。

所有数字都是 VLA-Perf/GenZ counters 上的 analytical what-if 结果，不是
CUDA/Triton kernel 实测。

## 4. 结果解释

流水线收益较小，因为 VLM 的连续算子几乎全部 compute-bound，资源下界已经
接近原始串行 Roofline 延迟；Fusion 后相关链也已经落到同一资源下界，因此
`pipeline + fusion` 在默认配置中没有继续下降。这不是代码没有执行，而是两种
优化在这些链上消除了同一段临界路径余量。

融合主要改善 Vision Attention 和 memory-bound Action Expert。Online
Attention 不重复扣除 GenZ 已经放在片上的 score matrix；Action prefix attention
也只消除直接的 query 边，prefix K/V 继续按 HBM 访问。

跨帧重用收益最大，但同时是风险最高的一项。模型将跨帧缓存按 HBM 访问计费，
并逐算子比较“缓存路径”和“直接重算”：H100 默认实验的 270 个候选中实际应用
243 个，27 个 Vision Logit 因读取缓存更慢而回退。缓存足迹约 1758.45 MB。
真实系统还必须验证 feature error、cache false-hit、动作成功率和动态回退开销。
